# RoomSensor (ESP32 PID Controller)

![MIT License](https://img.shields.io/badge/License-MIT-green.svg)

This project is the MCU component of the **[SimulationTempRatutureProgram](https://github.com/EddieKarlsen/SimulationTempRatutureProgram)**  ecosystem. It implements a PID-based temperature controller on an ESP32. The system receives environmental data via UART in JSON format, calculates the necessary heating power, and returns the PID signal.

## Requirements
* **ESP-IDF v5.1.1+** (Tested on v5.1.1)
* **cJSON** (Managed via IDF Component Manager)

## Configuration
All primary settings are located in main/inc/config.h.

Adjust these constants to tune your controller:
* KP: Proportional gain - Controls immediate reaction to error.
* KI: Integral gain - Eliminates steady-state error.
* KD: Derivative gain - Dampens oscillations.


## Communication Protocol
Inbound (From Simulation)
JSON
```text
{
  "outdoor_temp": -5.0,
  "indoor_temp": 20.5,
  "airflow_rate": 0.5,
  "solar_intensity": 150.0,
  "humidity": 65.0,
  "timestamp": 1704374400.0
}
```
Outbound (From ESP32)
JSON
```text
{
  "heating_power_pct": 65.5,
  "setpoint": 21.0,
  "error": 0.5,
  "pid_p": 1000.0,
  "pid_i": 500.0,
  "pid_d": 250.0,
  "timestamp": 1704374401
}
```
